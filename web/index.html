Go, running inside browser Linux

Check whether a standard Go toolchain can support the next Foundry course. Compile a program, run tests, coordinate goroutines, and save and reopen a small database.

The prepared filesystem contains Go 1.27.4, a build cache and the example sources. It boots in the hosted Linux emulator; you do not install Go on your computer or create an account.

This is a runtime prototype. Linux needs internet access and uses this device’s CPU and memory. Export guest files before stopping or reloading.

Prepare the session

  1. Start Linux. Wait for the go-foundry:~# prompt and Go workspace prepared message.
    Open terminal in a separate tab

    The Linux VM has not started.

  2. Confirm the toolchain. Go and the project are already prepared at boot. Choose Copy workspace command, click the terminal and paste. The command enters the working directory and prints the installed Go version.
    Loading toolchain information…
  3. Run a check below. Compilation can take a minute or more in this emulator. Keep the same Linux session open for repeat runs. A completed setup is confirmed by the terminal message Go workspace prepared.

Keep your work
Guest files survive commands and check changes in this page, but not Stop Linux, a browser reload or a closed tab. Browser editor drafts are saved separately. Export a work archive before ending the guest session.
cd /root/work && tar czf /root/go-foundry-work.tar.gz --exclude='go-foundry/.bin' --exclude='go-foundry/.go-cache' --exclude='go-foundry/.go-path' go-foundry && export_file /root/go-foundry-work.tar.gz
In a fresh session, wait for the prepared workspace prompt. Upload your work archive using the terminal’s upload control, then restore it with:
tar xzf /root/go-foundry-work.tar.gz -C /root/work && cd /root/work/go-foundry && ./run db-read
Restoring replaces the fresh project with your exported source and data. Export the current guest first if it contains work you want to keep.

Code runner
The guest is configured with 768 MiB RAM; browser and compiler overhead require additional memory. An open terminal is not confirmation that Go is ready—inspect its prompt and setup message.
Automatic stopping is disabled because this prototype cannot save guest files automatically. Export a work archive before stopping. Browser editor drafts are kept.


Stop Linux?
Export a work archive first. Stopping clears the guest’s files and running programs. Your browser editor drafts are kept.


App status
This is a Go runtime prototype. The Go SDK and prepared cache are versioned course-owned files, and minimal Linux root filesystem are served by this site. JSLinux serves the emulator and kernel.
A fresh Linux session needs internet access. No complete offline Linux copy is offered. Downloaded source and work archives can be kept independently.
Version and implementation details
The hosted terminal is on another origin. This page cannot inspect its prompt, run a command, or save its files automatically. Copy and paste commands, and use its upload/export controls.
